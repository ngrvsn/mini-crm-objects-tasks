# Как работает мини-CRM

Демонстрационный стенд: [https://120nmine.tech/crm](https://120nmine.tech/crm).

Руководитель создаёт строительные объекты, добавляет к ним задачи и назначает исполнителей. Исполнитель видит свой список задач, берёт задачу в работу и передаёт результат на проверку. Руководитель принимает результат либо возвращает задачу с обязательным комментарием о том, что нужно исправить. В карточке задачи видно, кто и когда менял её статус.

При вводе адреса приложение предлагает варианты из OpenStreetMap; адрес можно вписать вручную. После смены статуса появляется короткое уведомление. У принятой задачи редактирование заблокировано, а текст при наведении объясняет причину.

Доступ проверяется самой базой данных, а не только кнопками на экране. Поэтому исполнитель не сможет открыть чужую задачу или изменить её статус, даже если попытается отправить запрос вручную. Он также не может создать объект, назначить себе чужую задачу, принять свою работу или изменить историю. Удалённые через интерфейс задачи скрываются, но записи об их выполнении сохраняются.

Пользователи не регистрируются сами: учётные записи создаёт администратор. После входа браузер хранит короткоживущий пропуск только в памяти, а ключ для продления входа лежит в защищённой cookie, недоступной коду страницы. Секретные ключи базы не попадают в приложение и репозиторий.
